# Деловая колбаса 038 — лендинг мясной лавки

Одностраничный сайт для мясной лавки «Деловая колбаса» (Иркутск, Instagram [@delovaiakolbasa038](https://www.instagram.com/delovaiakolbasa038/)). Готов к публикации на любом статическом хостинге: достаточно загрузить содержимое папки в корень сайта.

## Структура

```
index.html            — страница
css/style.css         — стили
js/main.js            — скрипты (без библиотек)
img/                  — фото в WebP (480 и 960 px) + JPG-запасной вариант, иконки, og-image
favicon.svg, apple-touch-icon.png, site.webmanifest
robots.txt, sitemap.xml, llms.txt — SEO и GEO
.htaccess             — сжатие и кэширование (Apache)
```

## Блоки страницы

1. Шапка с бургер-меню на мобильных
2. Первый экран «Мать всех колбас и сосис» + бегущая строка с новинкой
3. Лавка — ассортимент с кнопками «В заказ»
4. Новинка — salami beef
5. Почему у нас
6. Хозяйка — Маргоша
7. Маршрут доставки на неделю с поиском своего района
8. Отзывы — слайдер (кнопки, точки, свайп, автопрокрутка)
9. Конструктор заказа — копирует текст и открывает Instagram Direct
10. Частые вопросы
11. Контакты и карта (Иркутск, ул. Аксакова, 2)

## Перед публикацией

- [ ] Заменить домен `delovaiakolbasa038.ru` на реальный в `index.html`, `robots.txt`, `sitemap.xml`, `llms.txt`
- [ ] **Заменить тексты отзывов на реальные** (из комментариев и сторис клиента) — сейчас в слайдере образцы для макета
- [ ] Уточнить точные координаты точки самовывоза для `geo.position` / `ICBM` (сейчас указан центр Иркутска)
- [ ] Сверить название района «Бармия» в маршруте четверга (взято как есть из описания) и добавить телефон, если клиент хочет его показывать
- [ ] Проверить формулировки в блоке «Почему у нас» с хозяйкой

## Совместимость

Safari iOS 12+, Chrome Android, Chrome/Edge/Firefox/Safari на десктопе. Учтены вырезы экрана iPhone (safe-area), автоувеличение полей на iOS, `prefers-reduced-motion`, навигация с клавиатуры.
